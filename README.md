# 株トレード練習ツール

過去の株価チャートを1日ずつ進めながら、売買の練習をするためのツールです。
PCとiPhoneで同じファイル（`index.html`）を使い、画面の大きさに合わせて自動で表示を切り替えます。

- 公開URL：https://sumi-kabu.github.io/kabu/
- iPhone：Safariで公開URLを開き「共有 → ホーム画面に追加」（「Webアプリとして開く」をオン）。以後はアイコンから開く
- お試し用：`test.html` をアップロードすると https://sumi-kabu.github.io/kabu/test.html で試せる

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | ツール本体（PC・iPhone共通）。**ファイル名は変更しない** |
| `README.md` | この説明 |

株価の取得にはGoogle Apps Script（GAS）を使用しています。GASのコードはGoogleアカウント側で管理しています（このリポジトリには置いていません）。

## 主な機能

- 日足・週足・月足の切り替え、表示数の変更
- 移動平均線：短期・中期（可変）、20・60・100・300MA
- 売買の練習（売・買の追加と決済、一括決済、損益の計算）
- 水平線（PCはマウス、iPhoneは指で操作）
- クイックセーブ（練習の途中を保存・読込）
- MAの値の記憶（変更すると、次に開いたときもその値で始まる）

## PCとiPhoneの違い

開いたときの画面の大きさで自動判定します（向きを変えた場合は開き直しで切り替わります）。
PCでもURLの最後に `?mode=mobile` を付けるとiPhone用の画面を確認できます。

| 項目 | PC | iPhone |
|---|---|---|
| 画面構成 | 右側に操作パネル | 上にチャート、下に左右2列のパネル |
| 表示数の初期値 | 80 | 40 |
| 水平線の操作 | マウス | タッチ |

## データの保存場所

すべて**各端末のブラウザの中**に保存されます。GitHubには上がりません。端末どうしでは共有されません。

| データ | 保存のされ方 |
|---|---|
| GASのアクセスキー | 端末ごとに最初の1回だけ入力して記憶 |
| MAの値 | 端末ごとに記憶（クイックセーブを読み込んだときの値は記憶しない） |
| クイックセーブ | 端末ごと |
| 株価データ | 開いた銘柄ごとに端末内へ保存（最大10年分） |

注意：
- iPhoneは、ホーム画面のアイコンとSafariとで保存場所が別になります。必ずアイコンから開くこと
- アイコンを削除して追加し直すと、保存データは消えます（アクセスキーの入力も再度必要）

## 株価の取得のしくみ

- 初回：まず2年分をすぐ表示し、そのあと10年分を読み込む
- 2回目以降：保存データをすぐ表示し、最近の分（5日分／間が空いていれば1か月分）だけ取得してつなげる（差分取得）
- 次の場合は自動で10年分を取り直す
  - 前回の全期間の取得から7日たったとき
  - 25日以上開いていなかったとき
  - 株式分割などで保存データとの値のずれを見つけたとき
- エラー対策
  - 待ち時間の上限あり、自動で最大3回やり直し
  - 失敗したら「前回データを表示中（取得失敗: 理由）」と表示し、保存データで続けられる

### GAS側

- アクセスキーが一致しないと株価を返さない（キーはGASのスクリプトプロパティ `ACCESS_KEY` に保存）
- 場中（平日 8:55〜15:45）は1分以内の新しいデータ、場外は6時間保存したデータを返す
- Yahooへの取得に失敗したら予備サーバーで再試行し、それでもだめならGASに残っている前回データを返す

## 更新のしかた

1. リポジトリで「Add file → Upload files」
2. 新しい `index.html`（同じ名前）をドラッグ＆ドロップ
3. 「Commit changes」
4. 1〜3分で反映。iPhoneはアプリを完全に終了して開き直す

過去の版は `index.html` を開いて「History」から確認・ダウンロードできます。
